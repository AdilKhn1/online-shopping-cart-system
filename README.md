# Online Shopping Cart System

## Project Overview
The **Online Shopping Cart System** is a web-based e-commerce application that allows users to register, log in, browse products, and add items to a shopping cart. The project demonstrates the basic working of an online shopping platform and the interaction between frontend and backend technologies.

## Features
- User Registration  
- User Login Authentication  
- Display Products on Home Page  
- Add Items to Shopping Cart  
- View Cart Items  

## Technologies Used

### Frontend
- HTML  
- CSS  
- JavaScript  
- Fetch API  

### Backend
- Java Servlets  
- JDBC  

### Database
- MySQL  

### Tools
- Eclipse IDE  
- Apache Tomcat Server  
- Git & GitHub  

## How to Run the Project
1. Install **Java JDK** and **Apache Tomcat**.  
2. Import the project into **Eclipse IDE**.  
3. Configure the **MySQL database** connection in JDBC.  
4. Run the project on **Tomcat Server**.  
5. Open the application in a web browser.

## Learning Outcomes
- Understanding of **client-server architecture**  
- Implementing **user authentication**  
- Using **Fetch API** for client-server communication  
- Connecting Java applications to **MySQL** using **JDBC**  
- Building a basic e-commerce workflow
