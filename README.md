# Online Shopping Cart System

## Description
The Online Shopping Cart System is a simple e-commerce web application that allows users to register, log in, view products, and add items to a shopping cart. The project demonstrates the basic workflow of an online shopping platform.

## Features
- User Registration and Login
- Product Listing on Home Page
- Add Items to Cart
- Cart Management

## Technologies Used
- Java (Servlets)
- JDBC
- JavaScript (Fetch API)
- HTML
- CSS
- MySQL (Database)

## Tools
- Eclipse IDE
- Apache Tomcat Server

## Purpose
The purpose of this project is to understand the development of a web-based application using Java Servlets, JDBC for database connectivity, and Fetch API for client-server communication.
